# PZF výpis — Chrome rozšírenie

Po tom, čo **vy** zaškrtnete „Nie som robot“ na Katastri (ÚGKK), toto rozšírenie odošle HTML výpisu do [PZF Explorer](https://solexecution.github.io/pozemkovyfond/). Captcha nerieši, neobchádza ani nerieši za vás.

## Inštalácia (raz)

1. Stiahnite zdroj z GitHubu: [Download ZIP](https://github.com/solexecution/pozemkovyfond/archive/refs/heads/main.zip) a rozbaľte ho, **alebo** naklonujte repo.
2. V Chrome otvorte novú kartu a do adresného riadka zadajte `chrome://extensions`.
3. Zapnite **Vývojársky režim** (vpravo hore).
4. **Načítať rozbalené** → vyberte priečinok `extension/` (ten s `manifest.json`).

Live aplikácia: https://solexecution.github.io/pozemkovyfond/

## Použitie

1. V PZF kliknite **Výpis** — otvorí sa Kataster ako doteraz.
2. Zaškrtnite „Nie som robot“. To musíte vy.
3. Keď sa ukáže výpis z LV, PZF ho načíta samo (parcely, m², podiel).

Bez rozšírenia ostáva záložka „PZF: načítať výpis“ a schránka.
